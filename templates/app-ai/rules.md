# App rules

Start with the [shared app rules](../../ai/resources/app_common_rules.md), then apply the runtime-specific rules below.

## Ownership

- Keep implementation changes inside this app unless the change belongs in `packages/shared`.
- Keep scope and acceptance criteria in `../docs/plan.md`.
- Keep actual status and verification evidence in `../docs/progress.md`.

## Verification

- Verify affected user flows on desktop and mobile when the UI changes.
- Do not describe a planned, simulated, or deferred feature as implemented.
